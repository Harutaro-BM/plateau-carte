# 建築年の「正しさ」は検証できなかった

実施 2026-08-19 / 判定 **不成立。識別子が噛み合わない**

## やろうとしたこと

カルテは「属性が**入っているか**」を測っている。限界表記にこう書いていた。

> 属性の意味：「入っている」を測るだけで、値が正しいかは測っていない

この穴を埋めようとした。
静岡市が公表する要安全確認計画記載建築物**31棟は、すべて昭和56年5月31日以前に
建築されたことが行政に確認されている**。つまり「建築年 ≤ 1981」という真値が
住所付きで31件手に入る。公的な正解が存在するのは稀である。

## やったこと

| 段階 | 結果 |
|---|---|
| 公表PDFから抽出 | **31棟**（葵区22／清水区6／駿河区3、評価Ⅰ9・Ⅱ11・Ⅲ11） |
| ジオコーディング（地理院） | **31/31 成功**（街区レベル） |
| 静岡市のPLATEAU全解析 | **351,871棟**（833メンバ、転送171MB、建築年60.4%） |
| 街区内に建物を発見 | 30/31 |
| うち建築年あり | **27（90%）** |
| **1981年以前と判定** | **14/27（52%）** |

## しかし52%は突合方法の産物だった

「街区内で最大の床面積の建物を候補とする」という規則を使ったが、これが壊れていた。

| 公表側の住所 | 突合されたPLATEAU建物 |
|---|---|
| 本通二丁目３番地８ ／ ４番地１ ／ １番地３ | **すべて同一**（1966年・26.2m・990m²） |
| 追手町259-6 ／ 馬場町11-2 ／ 追手町229-16 ／ 追手町259-6 | **すべて同一**（1975年・57.0m・4560m²） |
| 二の丸町301番地 ／ 305番地 | 同一（1973年・4.9m・359m²） |
| 清水区秋吉町144番地３ ×2 | 同一（2008年・7.1m・944m²） |

**隣接する別々の公表建物が、同じPLATEAU建物に潰されている。**

そして「×」と出た13棟の建築年は1986・1986・1986・1987・1989・2002・2004・
2008・2008・2012・2015・2016・2019 と新しい。
たとえば清水区秋吉町144番地3は**静岡県立清水東高等学校**で、
公表対象は管理教室棟と第1体育館（旧耐震）だが、
**キャンパス内で最大の建物は新しい棟**である可能性が高い。

**つまりこの測定は、PLATEAUの建築年の精度ではなく、私の突合規則の質を測っていた。**

## 根本原因：識別子が噛み合わない

| 側 | 建物の識別方法 |
|---|---|
| 公表リスト | **建物の名称**（ハイツ元城、ＮＴＴ長沼ビル、静岡南郵便局…） |
| PLATEAU | **名称を持たない** |
| ジオコーディング | **街区（○丁目○番）まで。街区には2〜26棟ある** |

**建物名という識別子が無い限り、公的リストとの建物単位の突合は成立しない。**
これは年度間変化検出（gml_idとbuildingIDが継承されない）と同じ型の問題である。

## 副作用：東京の反転率0%も条件付きになる

東京で測った「高さ34.0〜144.3m／閾値±1.75m内 0%」も、
**同じ「街区内で最大」という仮定に依存している。**

中央区・台東区の商業街区は全棟が高層なので結論は保ちやすいが、
**静岡では高さが4.9〜57.0mと幅広く、仮定が効かない。**
地域によって成立しないので、あの0%は「高層密集街区では頑健」という限定つきの結果である。

## 言えること・言えないこと

**言えないこと**
- PLATEAUの建築年が正しいかどうか。**検証できていない**

**言えること**
- 建築年の値は**1966〜2019の妥当な範囲**に収まり、ダミー値は無い
- 14棟は旧耐震と一致し、1966年26.2m/990m²、1975年57.0m/4560m² といった値は
  大規模な古い建物として整合的である
- **静岡市のPLATEAUは351,871棟で建築年60.4%**（3メッシュ標本では73.2%。
  サンプリング誤差の実例として12.8ptのずれ）

## カルテへの影響

**限界表記は据え置く。**穴を埋められると思ったが、埋められなかった。

> 属性の意味：「入っている」を測るだけで、値が正しいかは測っていない

そして**新しい限界を1つ追加する。**

> **PLATEAUには建物名が無いため、名称で建物を識別する公的資料との突合ができない。**
> 建物単位の照合を要する検証は、この制約を先に確認すること。
